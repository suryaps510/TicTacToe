# Tic Tac Toe - Java Swing

A simple Tic Tac Toe game built using Java Swing.

## Features
- 2-player X/O gameplay
- 3x3 GUI board
- Prevents overwriting occupied cells
- Winner detection
- Draw detection
- Play Again / Exit functionality

## Technologies
- Java
- Java Swing

## Concepts Practiced
- 2D Arrays
- Loops
- Methods
- Event-driven programming
- GUI components
- Game state management
